# 交付前验收清单

按本次改动范围执行相关项。任一核心项失败都不能声称完整交付。

## 核心行为

- [ ] 单张和多张 JPG、PNG、WebP 可以导入，其他格式有明确提示。
- [ ] 导入后自动进入 AI 分析状态；刷新后中断任务会恢复。
- [ ] 每张建议 5～8 个标签，且全部存在于 `taxonomy.json`。
- [ ] 用户确认前，建议标签不会计入正式筛选和搜索。
- [ ] 用户可以删除建议、从规范词库补选并确认；不能意外创建自由词。
- [ ] AI 失败时图片仍在本地，可重新识别或手动选择标签。
- [ ] 刷新和重新打开同一地址后，图片、标签、备注仍存在。
- [ ] 标签可添加、移除和复用，单张素材最多 8 个正式标签。
- [ ] 两个或更多标签筛选只返回同时包含全部选中标签的素材。
- [ ] 文件名、标签和备注搜索都能命中；无结果时状态清晰。
- [ ] 大图可查看，导出原图后文件可打开且格式不变。

## 数据安全

- [ ] 成功提示发生在写入完成之后；失败不会显示假成功。
- [ ] 完整备份包含图片字节及全部元数据。
- [ ] 备份可在独立空测试库恢复，恢复后原图和标签一致。
- [ ] 非法或不支持的备份不会写入半套数据。
- [ ] 删除前确认，删除只影响库内副本。
- [ ] 前端构建产物、IndexedDB、日志与备份中都没有 API Key。
- [ ] UI 与说明书明确写明 AI 分析会把当前图片发送到配置的服务。

## 界面与质量

- [ ] 导入、搜索、待整理、筛选、详情和备份入口在首屏可发现。
- [ ] 键盘焦点可见，按钮和正文对比清楚。
- [ ] 缩略图不被拉伸，长文件名不会撑坏布局。
- [ ] 空库、无结果、AI 分析中、待确认、AI 失败、保存和恢复都有对应反馈。
- [ ] `npm run build` 通过，浏览器控制台没有未处理错误。
