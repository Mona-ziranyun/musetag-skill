# MuseTag

核心操作固定为：**拖入图片 → AI 从规范词库推荐 5～8 个标签 → 用户删除或补选 → 确认完成**。未确认建议不进入正式标签；AI 不得创建词库之外的新词。

## 先判断任务类型

动手前把请求归入最贴近的一类，并只加载该类需要的细节：

- **新建**：从模板生成可运行项目。阅读 [references/product-spec.md](references/product-spec.md)、[references/tag-taxonomy.md](references/tag-taxonomy.md) 与 [references/ui-quality.md](references/ui-quality.md)。
- **改进**：先检查现有结构、数据版本和真实问题，再增量修改。涉及界面时读 UI 规范；涉及数据时读存储规范。
- **排查**：先复现并说明原因；用户只要求诊断时不要顺手改代码。
- **扩展**：修改 AI 提示、模型或数据流时读 [references/ai-integration.md](references/ai-integration.md)；Eagle、云同步或移动端读 [references/extensions.md](references/extensions.md)。

只有当不同答案会明显改变数据模型、隐私边界或交付形式时才问一个简短问题；其余情况基于现有项目和用户原话合理推断。

## 新建项目

新项目优先从随 Skill 附带的可运行模板开始，而不是只画静态页面：

```bash
python3 scripts/create_asset_box.py <目标目录>
cd <目标目录>
npm install
npm run dev
```

如果目标目录已有项目，先检查现有结构并在原项目内增量修改，不要直接覆盖。模板位于 `assets/starter/`，不应把 Skill 自身目录当作用户数据目录。

## 产品边界

坚持这些默认约束：

- 不登录、不云同步；原图与元数据保存在当前浏览器。
- 导入后自动发起 AI 看图；界面必须明确说明图片会发送到配置的 AI 服务。
- API Key 只能由本地服务端读取，不得写入前端源码或浏览器存储。
- 支持 JPG、PNG、WebP 的拖入、文件选择和多张导入。
- 图片原文件与标签、备注、来源链接一起存储；写入成功后才能提示成功。
- AI 每张推荐 5～8 个标签，且只能来自 `assets/starter/src/taxonomy.json`。
- 用户以删除、确认和有限补选为主，不默认开放自由造词；多个筛选标签使用 AND 逻辑。
- 未确认建议与正式标签分开保存；识别失败时仍可从规范词库手动选择。
- 可看大图、改标签、导出原图；删除库内副本前确认，不碰来源文件。
- 备份必须同时包含原图和元数据，并能恢复到另一个空测试库。
- 明确提醒浏览器本地存储不是唯一保险箱，试用期保留来源原图。

改变 IndexedDB、导入、删除、备份或恢复逻辑前，必须阅读 [references/storage-and-backup.md](references/storage-and-backup.md)。

## 界面判断

这是高频操作型产品，不是营销页或数据看板。信息层级按“导入与搜索 → 素材结果 → AI 标签确认”组织；让分析中、待确认、失败和保存反馈可见。默认使用卡其、米白、灰绿的低饱和配色，避免无用途的统计卡片、装饰性动画和过多弹窗。

不要因为用户说“高级感”就牺牲缩略图密度、标签可读性或键盘操作。视觉改动遵循 [references/ui-quality.md](references/ui-quality.md)。

## 修改现有项目

先检查数据结构、存储版本和已有用户数据。数据库升级使用向前兼容迁移；不要为了界面调整清空 IndexedDB。保留用户已有标签和素材，除非用户明确要求迁移或删除。

若用户要求 Eagle 插件、云同步或移动端，把它视为独立扩展：先确认目标与数据流，再扩展；不要悄悄改变本地优先的默认方案。

## 验证

交付前至少运行 `npm run build`。能进行浏览器测试时，按 [references/acceptance-checklist.md](references/acceptance-checklist.md) 验证真实行为，而不是只检查页面文字或代码结构。

至少守住五个交付门槛：

1. **收藏门槛**：图片可快速导入并自动开始 AI 分析。
2. **标签门槛**：AI 推荐 5～8 个规范词，确认前不污染正式标签库。
3. **找回门槛**：搜索与多标签 AND 筛选返回正确素材。
4. **取用门槛**：大图和导出的原图可正常打开。
5. **安全门槛**：刷新不丢数据，完整备份能恢复，删除不碰来源文件，密钥不进入前端。

如果当前环境不适合做完整浏览器交互测试，明确说明已验证的部分和仍需用户手动验证的部分。
